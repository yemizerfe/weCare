# weCare client

The React/Vite client for weCare. For local setup, API configuration, and deployment instructions, see the [project README](../README.md).

Available scripts:

- `npm run dev` — start the Vite development server.
- `npm run build` — create the production bundle in `dist`.
- `npm run lint` — run ESLint.
- `npm run preview` — preview the production bundle locally.

Copy `.env.example` to `.env` to configure the API URL or the local development proxy.
